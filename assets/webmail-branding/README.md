# Bulwark Webmail 3D Dimensional Branding Pack (v3)

Includes high-resolution raster, multi-layer ICO, and vector assets with directional lighting, specular highlights, and beveling.

## Assets Included:
- `png/`
  - `app-logo-24.png` (24x24 px sidebar native target)
  - `app-logo-48.png` (48x48 px retina 2x)
  - `app-logo-128.png` (128x128 px ultra retina)
  - `login-logo-256.png` & `login-logo-512.png` (Login screen branding)
  - `favicon-16.png`, `favicon-32.png`, `favicon-48.png`
  - `apple-touch-icon.png` (180x180 px iOS bookmark)
  - `icon-192.png`, `icon-512.png` (PWA / Android app icons)
- `svg/`
  - `logo-app-icon.svg` (Full 3D squircle app icon)
  - `logo-light.svg` & `logo-dark.svg` (Transparent background 3D vectors)
- `ico/`
  - `favicon.ico` (Multi-resolution 16/32/48 px icon)
- `bulwark.env.example` (Ready-to-use environment template)
